# Fundamentals of Computers

## What is a Computer?
A computer is an electronic device that accepts data, processes it according to instructions, stores it, and produces meaningful information.

## Characteristics
- Speed
- Accuracy
- Storage
- Automation
- Versatility
- Reliability

## Basic Components
### 1. Input Unit
- Keyboard
- Mouse
- Scanner
- Microphone

### 2. CPU (Central Processing Unit)
The brain of the computer.

#### ALU (Arithmetic Logic Unit)
- Performs arithmetic operations
- Performs logical operations

#### CU (Control Unit)
- Controls all computer operations

#### Registers
- Temporary storage for processing

### 3. Memory Unit
#### Primary Memory
- RAM
- ROM

#### Secondary Memory
- HDD
- SSD
- USB Drive
- CD/DVD

### 4. Output Unit
- Monitor
- Printer
- Speakers
- Projector

# Computation

## Definition
Computation is the process of processing data according to a set of instructions to produce meaningful results.

## Steps of Computation
1. Input
2. Processing
3. Storage
4. Output

## Types of Computation
- Arithmetic Computation
- Logical Computation
- Data Processing

### Example
Input: 25 + 15

Output: 40

# Computer Network

## Definition
A computer network is a collection of interconnected computers that share data and resources.

## Advantages
- File Sharing
- Resource Sharing
- Internet Access
- Communication
- Centralized Storage
- Faster Data Exchange

## Types of Networks
### LAN (Local Area Network)
- Small geographical area
- High speed

### MAN (Metropolitan Area Network)
- Covers a city

### WAN (Wide Area Network)
- Covers countries or continents
- Example: Internet

## Network Devices
- Router
- Switch
- Hub
- Modem
- Access Point

## Network Topologies
- Bus
- Star
- Ring
- Mesh
- Tree

## Communication Media
### Wired
- Twisted Pair Cable
- Coaxial Cable
- Optical Fiber

### Wireless
- Wi-Fi
- Bluetooth
- Cellular Network
- Satellite

## Common Protocols
- TCP/IP
- HTTP/HTTPS
- FTP
- SMTP

## Applications
- Online Learning
- Banking
- Video Conferencing
- Cloud Computing
- E-commerce
- Social Media
